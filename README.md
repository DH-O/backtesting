This code backtest portfolios.  
The backtest code also provides results in Korean Won (KRW).  
All data is based on yahoo finance.  

You should install as below
```
pip install -r requirements.txt
```

You can edit your portfolios from portfolio_configs.yaml and config.py  
If you want to get backtesting results, please run 'run_backtest.py' as below
```
python run_backtest.py
```
